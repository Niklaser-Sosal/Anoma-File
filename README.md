# Anoma-File

**BNMA / BINOMA → Конвертер в GLB для всех.**

Anoma-File — это настольное приложение, интерфейс которого построен как веб-интерфейс (HTML/CSS/JavaScript), в то время как Python обеспечивает нативный мост для Windows и движок конвертации.

---

## Что делает приложение

Anoma-File предоставляет графический интерфейс для конвертации поддерживаемых файлов моделей **`.bnma`** и **`.binoma`** в файлы **`.glb`**.

Интерфейс включает:

- Домашнюю страницу с информацией о приложении и недавней активностью
- Страницу конвертации BNMA/BINOMA → GLB
- Выбор файлов перетаскиванием
- Выбор пути для выходного файла
- Опциональное извлечение FBX
- Параметры встраивания текстур
- Параметры сжатия текстур
- Контроль качества
- Индикатор прогресса конвертации
- Журнал конвертации
- Страницу пакетной конвертации
- Страницу настроек
- Ассоциации файлов Windows для `.bnma` и `.binoma`

Интерфейс является локальным. Для его работы не требуется веб-сервер и подключение к Интернету.
